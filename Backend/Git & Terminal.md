#### **Git Commands** 

git init	           Current folder mein Git repository initialize karta hai.

git status	           Current changes aur branch status dikhata hai.

git add filename	   Specific file staging area mein add karta hai.

git add .	           Current directory ke changes stage karta hai.

git commit -m "message"	   Staged changes ka snapshot save karta hai.

git push	           Local commits GitHub par bhejta hai.

git pull	           Remote changes fetch karke current branch mein integrate karta hai.

git clone URL	           Existing remote repository ki local copy banata hai.

git log --oneline	   Commit history short format mein dikhata hai.

git diff	           Unstaged changes dikhata hai.

git diff --staged	   Staged changes dikhata hai.

git branch	           Local branches list karta hai.

git switch branch-name	   Branch switch karta hai.

git remote -v	           Remote repository URLs dikhata hai.

#### Terminal commands

Get-Location	                        Current directory batata hai.

Get-ChildItem	                        Current folder ki files/folders dikhata hai.

cd foldername	                        Folder change karta hai.

cd ..	                                Parent folder mein jata hai.

mkdir foldername	                New folder banata hai.

New-Item filename -ItemType File	New file banata hai.

Get-Content filename	                File ka content read karta hai.

Clear-Host	                        Terminal screen clear karta hai.

Get-History	                        Current PowerShell session ki command history dikhata hai.
